# SOE-Speak · 体制内话语三件套

> 一套把“人话 ↔ 官话 ↔ 官僚绕圈”互相转换的 Skill 工具箱。

## 三件套

| Skill | 方向 | 语气 | 用途 |
|---|---|---|---|
| **SOE Reframer** 国企正向话术翻译器 | 人话/吐槽/事故 → 正向汇报 | “我们坚持底线思维…” | 写汇报、邀功、合规表达 |
| **Humphrey Mode** 汉弗莱官僚话术模式 | 人话 → 官僚绕圈/暂缓/不背锅 | “正如您所料见的那样，大臣。” | 拖延、甩锅、优雅拒绝 |
| **Reverse Decoder** 官话翻人话解码器 | 官话/领导话 → 人话 | “你牵头一下 = 活你干锅你背” | 读懂意图、识别风险、避免背锅 |

## 七大题材（themes.yaml）

1. 风险防控 / 底线思维
2. 数据治理 / 网络安全
3. 降本增效 / 亏损治理
4. 合规 / 依法治企
5. 改革 / 治理现代化
6. 党建 / 担当
7. 事故复盘 / 故障转正

每个题材含：`tags`（触发词）+ `negative_examples`（吐槽样本）+ `positive_template`（正向模板）+ `keywords`（高频词）

## 组合用法（推荐流水线）

```
领导说话
   ↓ ③ 解码：他要啥？锅谁背？
   ↓ 判断
   ├─ 要写汇报 → ① SOE Reframer：坏事写成管理成果
   └─ 要拖延 → ② Humphrey Mode：成立工作组、广泛听取、待条件成熟
```

## 快速示例

**输入**：硬件坏了，数据丢了，领导让我牵头写复盘
**Step 2 解码**：真任务 + 锅在你（牵头=活你干锅你背）→ 必须留痕、拉清单、定分工
**Step 3 编码（soe-reframer · 题材 incident_review + data_governance）**：
> 我们坚持底线思维，主动将硬件故障纳入风险防控清单，通过冗余部署和定期演练，把“不可抗力”变为“可控变量”。此次事件虽造成部分数据损失，但影响可控、恢复有序，恰好验证了前期风险研判的准确性，也为推动灾备体系升级提供了实战依据。以实战促完善，以制度筑防线，发展的路才能越走越稳、越走越宽。

**如果领导催得太急（humphrey-mode）**：
> 大臣，您提出了一个极为关键的问题。鉴于其涉及跨部门协同、数据合规与舆情传导，贸然定稿恐生枝节。建议先行成立专项工作组，广泛听取各方意见，待条件成熟再呈报。正如您所料见的那样，大臣。

## 红线（三件套共用）

- 不把违规、违纪、违法包装成成绩
- 不虚构未发生的预案、演练、制度
- 数据类表述须注明真实状态（影响可控 / 已恢复 / 无泄露）
- 汉弗莱模式定位为**语言艺术研究 / 影视台词模仿 / 职场沟通演练**
