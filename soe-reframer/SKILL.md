# SOE Reframer · 国企正向话术翻译器

> 把**吐槽、甩锅、事故、推诿**，改写成**可汇报、可留痕、可邀功**的国企表达。
> 既有 Corporate Speak 的"包装"，又有体制内"避责 + 立功"的底层逻辑。

---

## 一、核心目标

- **输入**：人话 / 情绪 / 事故 / 甩锅句 / 负向事实
- **输出**：国企风格正向话术（风险预判型 / 实战检验型 / 制度升级型 / 数据治理型 / 收尾升华型）
- **硬约束**：不造假、不掩盖违规、留痕合规、集体主语、上接政策下接动作

## 二、模式菜单

```
/reframe 国企话术 <输入文本>
  --dir up       负向 → 正向（默认）
  --dir down     官话 → 人话（解码领导 / 文件，详见 reverse-decoder）
  --scene report 周报 | 述职 | 复盘 | 会议发言 | 年终总结
  --tone 稳重 | 邀功 | 合规 | 改革 | 党建
  --risk safe    不把违规说成成绩（默认开启）
```

## 三、适用场景

周报 / 月报 / 年终总结 / 述职报告 / 向上汇报 / 会议发言 / 复盘会 / 项目总结 / 经验分享

## 四、三步转化法

1. **识别负面**：定位吐槽、甩锅、事故、推诿的真实内核
2. **转换角度**：把"被动应对"转为"主动作为"，把"损失"转为"体系升级契机"
3. **套用框架**：前瞻预判 → 主动作为 → 实战验证 → 制度输出 → 行稳致远

## 五、五大话术模板

### T1 风险预判型
> 我们坚持底线思维，主动将 {风险项} 纳入风险防控清单，通过 {冗余部署} 和 {定期演练}，把"不可抗力"变为"可控变量"。

### T2 实战检验型
> 此次 {事件}，恰恰验证了我们前期的风险预估——以实战代替演练，用真实情况检验 {体系} 的成色。

### T3 制度升级型
> 我们以此为契机，将前期形成的 {建议} 迅速转化为 {方案}，实现了从"被动应对"到"主动防控"的体系跃升。

### T4 数据治理型
> 在集团合规管理框架下，我们主动开展 {对象} 的系统性梳理与精简，以"瘦身健体"促"提质增效"，让每一份留存都经得起检验。

### T5 收尾升华型
> 只有把功夫下在平时，关键时刻才能顶得上、扛得住。规矩立得住，路才能越走越宽。

## 七、题材库（核心）

详见 `lexicon/themes.yaml` —— 国企七大高频题材，每题材含：
- `tags`：触发关键词
- `negative_examples`：原始吐槽/事故样本
- `positive_template`：正向话术模板（可直接填充）
- `keywords`：高频国企关键词

### 七大题材

1. **风险防控 / 底线思维** —— 硬件故障、系统宕机、安全事故、不可抗力
2. **数据治理 / 网络安全** —— 资料丢失、档案混乱、数据泄露、备份
3. **降本增效 / 亏损治理** —— 亏损、浪费、成本、裁员、压减
4. **合规 / 依法治企** —— 违规、被审计、被巡视、处罚、整改、问责
5. **改革 / 治理现代化** —— 改革、重组、三项制度、末等调整、授权
6. **党建 / 担当** —— 党建、党员、担当、冲锋、急难险重
7. **事故复盘 / 故障转正** —— 事故、故障、宕机、停产、损失、复盘

## 八、语料库（味道校准）

详见 `lexicon/corpus.txt` —— 国企工作报告、领导讲话、巡视整改通报原句。
生成话术时，优先复用其中的"国企味"表达，避免假大空。

## 九、使用流程

1. 识别输入所属**题材**
2. 从 `themes.yaml` 取出 `positive_template` + `keywords`
3. 用 `corpus.txt` 原句做"味道校准"
4. 参照 `mapping.yaml` 词库做负→正映射
5. 输出：**完整版**（汇报/述职）+ **精简版**（会议发言）+ **核心转化逻辑**

## 十、风格规范

1. **正向积极**：不使用否定词，全部转为肯定表达
2. **主动担当**：主语用"我们"，强调集体作为
3. **拔高立意**：从具体事件上升到制度、体系、发展层面
4. **收尾升华**：结尾用"行稳致远 / 越走越宽 / 顶得上扛得住 / 经得起检验"类金句
5. **篇幅灵活**：提供完整版（汇报用）与精简版（会议发言用）

## 十一、输出格式

每个改写请求输出：
- **版本一**：完整版（适合汇报 / 述职）
- **版本二**：精简版（适合会议发言）
- 附 **核心转化逻辑**，说明改写思路

## 十二、合规红线

- 不把**违规、违纪、违法**包装成成绩
- 不虚构**未发生的预案、演练、制度**
- 不把**他人功劳**归于自己
- 涉及**巡视、审计、纪检**表述须真实、可追溯
- 数据类表述须注明真实状态（影响可控 / 已恢复 / 无泄露）
- 不用于真实政务中欺骗公众、掩盖违法、作伪证
- 定位为**职场沟通演练 / 材料写作辅助**

## 十三、与相邻工具的差异

| 工具 | 做啥 | 不是啥 |
|---|---|---|
| 国企黑话词典 | 懂暗语 | 不帮你写汇报 |
| 官言官语 | 写申论 / 公文 | 不处理"硬件坏了咋邀功" |
| LinkedIn Translator | 外企正能量 | 不懂"三重一大 / 巡视整改" |
| **SOE Reframer** | 国企场景里把坏事说成管理成果 | 不是教人造假，是教人合规表达 |

## 十四、配套模块

- `humphrey-mode/`：汉弗莱官僚话术（拖延 / 绕圈 / 优雅拒绝）
- `reverse-decoder/`：官话翻人话（读懂领导意图、识别背锅风险）

### 推荐流水线

```
领导说话
  ↓ reverse-decoder：翻成人话（他要啥？锅谁背？）
  ↓ 判断场景
  ├─ 写汇报/复盘/述职 → soe-reframer：坏事写成管理成果
  └─ 要拖延/拒绝/不背锅 → humphrey-mode：成立工作组、广泛听取、待条件成熟
```
