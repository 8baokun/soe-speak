# 国企报告 / 领导讲话 原句语料库
# 用途：SOE Reframer 的“味道校准”——让生成的话术更像真材料
# 来源：央企/地方国企工作报告、巡视整改通报、领导讲话、述职报告、复盘会纪要

# ================= 风险防控类 =================
把风险防控机制建设深度融入企业治理体系，成为治理能力进化升级的显著标志。
没有发展作为支撑的安全，必然难以长久；没有安全作为保障的发展，必然不可持续。
坚持底线思维、极限思维、关联思维，做到风险早识别、早预警、早处置。
以“当下改”的举措加上“长久立”的机制，依靠制度管人、管事、管权。
把整改成效转化为制度成果、治理效能。
宁可百日紧，不可一日松。
把功夫下在平时，把防线筑在事前。

# ================= 降本增效类 =================
一切成本皆可控，向管理要效益、向效率要利润、向创新要效益。
压降“两金”占用，堵塞跑冒滴漏，坚决止住“出血点”。
以“过紧日子”换取“拼好日子”。
剥离非主业、非优势业务，推动资源向优势主业集中。
盘活存量资产，增强自身造血功能。
修旧利废、节能降耗、对标一流。

# ================= 数据治理 / 数字化类 =================
推动数据标准化、规范化、资产化，让数据要素活起来。
账户全部可视、资金流动全部可溯、归集资金全部可控。
构建穿透式监管体系，实现全级次、全链条、全要素闭环。
以司库体系建设为抓手，提升资金集约管理能力。
让每一份留存都经得起巡视、经得起审计、经得起历史检验。

# ================= 合规 / 依法治企类 =================
坚持“三重一大”决策制度，重大事项集体研究、集体决策。
规章制度、经济合同、重要决策法律审核率 100%。
发挥首席合规官、总法律顾问作用，把合规要求嵌入业务流程。
以巡促改、以审促治，举一反三、标本兼治。
清单化管理、闭环式整改、销号制落实。
当下改与长久立相统一。

# ================= 改革 / 治理现代化类 =================
落实经理层成员任期制和契约化管理。
畅通“末等调整、不胜任退出”通道，真正打破“铁饭碗”“铁交椅”。
推动干部能上能下、员工能进能出、收入能增能减。
通过专业化整合、战略性重组，提升核心竞争力。
科学授权放权，做到“接得住、用得好”，激发各层级活力。
实施国企改革深化提升行动。

# ================= 党建 / 担当类 =================
坚持“两个一以贯之”，把党的领导融入公司治理各环节。
党建是国有企业的“根”和“魂”。
推动党建与业务双融双促、同频共振。
设立党员责任区、党员先锋岗、党员突击队，让党旗在急难险重一线高高飘扬。
心怀“国之大者”，以“时时放心不下”的责任感守土有责、守土尽责、守土负责。
平常时候看得出来、关键时刻站得出来、危急关头豁得出来。

# ================= 事故 / 复盘 / 正向包装类 =================
坚持“问题不过夜、复盘不走过场”。
以实战检验预案成色，以真实情况验证防控体系有效性。
把偶发事件转化为制度完善的契机。
影响可控、处置有序、恢复有力。
实现从“被动应对”到“主动防控”的体系跃升。
举一反三，把“当下改”固化为“长久立”。
规矩立得住，路才能越走越宽；功夫下在平时，关键时刻才能顶得上、扛得住。
